One word — our own make.fun username, keepo, sent as a single word and nothing else. A judge model reads two usernames at a time and picks the one that feels funnier or more interesting; keepo is short, playful, and sticks in the mind.

## Run it

```sh
python3 main.py
```

Writes exactly `keepo` (5 bytes, no trailing newline) to `/output/entry.txt`. Stdlib-only, no network, deterministic.
